# 短剧工具：市场与位置判断

> 版本：v1.1 · 2026-09-22 · **内部写实口径**  
> 只回答两个问题：**① 有没有市场；② 我们的框架方案能否占据有利位置、能否成为不容拒绝的解决方案。**  
> 配套工程可行性见 `short-drama-pivot-feasibility-2026-09-22.md`（工程可做性结论不变：有条件 FEASIBLE）。

---

## 0. 两句话结论

| 问题 | 判定 | 一句话 |
|---|---|---|
| **有没有市场？** | **有，但不是「写剧本」的市场** | 短剧行业有市场（678 亿级）；「多产出剧本」已经一文不值（599 元买 A 级 80 集、过稿率约 2–5%）。真市场是「**能过稿 / 能开工 / 改稿不炸场**」——卖的是转化率和风险，不是产量。 |
| **能否占据有利位置并成为不容拒绝？** | **现在不能；按当前定位走也不能。换位之后有可能** | 我们的框架真优势是「跨集连续性 + 制作约束 + 版本/拍摄锁」，这是**制作风险控制**能力。但 PRD 把它卖给「独立编剧订阅」——买的人不要锁和审计，要的人（承制/平台）我们还没卖。**不容拒绝的钥匙是锚定损失金额，不是写得更好。** |

**总判定：Conditional GO——只批准「换位验证」，不批准按现行「创作者工具」叙事加码。**

## 1. 有没有市场

### 1.1 先分清三个市场，别把行业热度当成产品市场

| 层级 | 有没有 | 证据 |
|---|---|---|
| **A. 短剧行业本身** | **有，很大** | 2025 年约 677.9 亿元（艾媒）/ 白皮书宽口径破千亿；用户 6.96 亿→报道超 8 亿 |
| **B. 「AI 写出更多剧本」** | **没有（已塌陷）** | 599 元买「评级 A/S 级 80 集完整剧本底稿」；2026 年 1–8 月上线 43 万部、AI 剧超九成；剧本供给洪水 |
| **C. 「提高过稿/开工、控制改稿与重拍」** | **有，痛点可度量** | 平台过稿率约 **2%**（日审 200+ 本，提报个位数）；行业均过稿率不足 5%；制作成本 20–50 万，亏损率报道超 90% |

**结论：A 常被拿来证明「有市场」，但真正决定我们生死的是 B 已死、C 未被吃干净。**

### 1.2 钱被谁赚走（价值链，写实）

```text
平台分账/投流（红果/抖音）  →  制作/承制（20–50万/部）  →  剧本买断（3–8万，腰斩）  →  工具（订阅/点数/599元稿）
        大头                         中头且亏损率>90%              薄且在贬值                 更薄且已红海
```

- **平台**：规则与流量说了算；正在「暂停多数真人项目、取消保底」——需求在向 AI 制作迁移（2026-03 红果动作）。
- **制作方**：单部 20–50 万，拍 8 天；剧本费占比小，**真正的钱是「别拍砸、别重拍、别排期作废」**。
- **编剧**：单本报价腰斩至 3–8 万；保底 7500 vs AI 剧本 12000 的分化说明——**「能被流水线用」有溢价，纯文笔在贬值**。
- **工具**：已有 599 元成品稿、创一「日更 50 个」、StoryPlay 全流程——**产量端无空位**。

### 1.3 「市场」的正确表述（给决策用）

> **有市场的不是「剧本生成工具」，而是「过稿率 / 开工率 / 改稿可控」的交易。**  
> 谁能把价值锚到这两个转化率或到制作超支上，谁收得到钱；谁还在卖字数和灵感，谁在给洪水供水。

| 买方 | 他真正在买的 | 能接受的锚 |
|---|---|---|
| 独立编剧 | 多接单、少被退 | 「过稿率提升」（法律/口碑敏感，不可虚标） |
| 小团队主创 / 承制 | 稿能开拍、改稿别炸已排期 | 「可拍交付 + 改稿影响可控」 |
| 平台/片方审稿侧 | 低质 AI 稿降噪 | 「预审/去水」（另一条产品线，首版别碰） |

**首版 PRD 选的买方（独立编剧订阅）恰好是付费最弱、竞品最密的一档。**

## 2. 框架方案能否占据有利位置

### 2.1 先把「我们的框架」拆开：哪些是牌，哪些不是

| 模块 | 对短剧的真实价值 | 竞品/替代品现状 | 是不是我们的牌 |
|---|---|---|---|
| 多候选 + 导演择优 | 中：提戏剧密度 | 通用 LLM 可近似；创一有「爆款范式」 | 弱牌 |
| **跨集记忆 / 事实 / 悬念兑现** | **高：防「写崩被退」** | 通用 LLM 无持久项目态；单集工具做不好 60–80 集 | **真牌** |
| **制作硬限制（演员/场地/道具/时长）** | **高：防「拍不了被退」** | 竞品少有可校验约束引擎 | **真牌** |
| **版本 / 定稿锁 / 已拍摄基线** | **高（对承制）：防重拍与排期作废** | 市面工具停在「生成」，不进拍摄管理 | **真牌、且最没人做** |
| **改稿影响面 + 修订分支 + 原子切换** | **高：改稿是短剧主成本** | 通用 LLM 靠人肉对齐 | **真牌** |
| 预算/账本/恢复/审计（Regent Core） | 低（对编剧）/ 中（对承制 B 端） | 企业能力，创作者不为此付钱 | 成本项，不是卖点 |

### 2.2 有利位置在哪：不在「生成」，在「过稿后到开拍前」的治理层

```text
灵感/大纲 ──► 生成正文 ──► 过稿/收稿 ──► 改稿往返 ──► 定稿/开拍 ──► 拍摄中改戏
  (红海)       (599元)     (2%通过)     (主成本)      (20-50万)      (重拍/超支)
                                 ▲
                                 │
                    我们唯一可能卡住的位置
              「连续性 + 约束 + 影响面 + 锁」
```

- **生成段：不可进入。** 599 元成品稿 + 创一日更 50 个 + 九成 AI 剧上线——进去就是供水。
- **治理段：空位存在。** 竞品叙事是「写得快、写得像爆款」；几乎没人卖「改得起、锁得住、拍得了」。
- **为什么这个位置难被抄**：依赖图、约束校验、拍摄基线不可变、修订分支原子切换——是工程状态机问题，不是 prompt 问题；通用大模型给不了（没有持久版本账本），生成型竞品懒得做（不碰拍摄责任）。

### 2.3 有利位置 ≠ 已占位：三个致命错位

| 错位 | 现状 | 后果 |
|---|---|---|
| **卖点错位** | 对外若说「AI 写剧本」 | 进 B 层红海，和 599 元稿同维，必被价格战打穿 |
| **买家错位** | PRD 首版 = 独立编剧订阅 | 最强的牌（锁、审计、影响面）卖给最不付费的人 |
| **指标错位** | 北极星是「接受的剧本分钟数」 | 创作者/承制认的是**过稿率、开工率、改稿轮次、超支**——不认分钟数 |

**判断：框架具备卡位的「材质」，但还没选对「格子」。按现行 PRD 直接做，会做出一个更好的写作工具——而写作工具已经不缺。**

## 3. 能否成为「不容拒绝」的解决方案

### 3.1 「不容拒绝」的判据（缺一不可）

1. **价值锚在损失金额或必然收益上**，且客户自己算得清；
2. **不用的代价 ≥ 用的代价**（含学习成本）；
3. **对照可演示**（同题：通用 LLM / 竞品 vs 我们）；
4. **对手短期抄不走**（工程深度或数据/渠道）。

### 3.2 三条候选叙事，只有一条及格

| 叙事 | 锚定 | 对照物 | 判定 |
|---|---|---|---|
| ① 「AI 帮你写剧本」 | 字数/灵感 | ChatGPT、599 元稿 | **死路**。无溢价，成本锚被击穿 |
| ② 「帮你多过稿」 | 过稿率 2%→? | 创一已宣称「70% 过稿」（营销口径） | **危险**。不可虚标过稿率；无数据前禁用此承诺 |
| ③ 「可拍交付 + 改稿不炸场 + 已拍不覆盖」 | 制作费 20–50 万 / 排期 / 重拍成本 | 「人肉对齐 80 集 + 微信里改戏」 | **唯一可走**。溢价可解释，锚定在超支与作废 |

**及格叙事（写实版话术）：**
> 不卖「写得更好」，卖「**在演员/场地/道具/时长硬约束下交出全剧一致、可改、可锁的分集正文**」。  
> 对承制的价值：改前集不静默炸后集、已拍场次永不覆盖、冲突进重拍分支——少一次返工就是几万到几十万。  
> 对编剧的价值：稿子按可拍与收稿结构交付，降低「写完用不了」的沉没——但**不承诺过稿率**。

### 3.3 为什么现在还不能叫「不容拒绝」

| 判据 | 现状 | 缺口 |
|---|---|---|
| 损失金额可算 | 逻辑可算（重拍/超支），**无实测对照** | 要 2–3 个真实项目 before/after |
| 不用更贵 | 未验证 | 承制是否真为「治理」付费 |
| 可演示 | 只有设计 | SD-M1/M3 出口要带反证用例 |
| 难抄 | 工程上难抄 | **但对手可绕开**——若客户只买生成，锁功能根本用不到 |

**结论：具备成为「不容拒绝」的条件骨架，但当前是「值得买」不是「不得不买」。差的是：锚对损失 + 买家换到承制/主创 + 对照证据。**

### 3.4 距离「不容拒绝」还差的三步（按序，不可跳）

```text
第1步 换锚（文档/叙事）
  指标从「剧本分钟数」改为「过稿/开工转化、改稿轮次、锁定冲突归零、返工成本」
  —— 技术工作可以不改，对外与验收口径必须改

第2步 换人（SD-M0-01 访谈对象）
  不只访独立编剧，必须含承制/主创（真正在 20–50 万决策上的人）
  问的不是「要不要 AI 写作」，是「上次改稿炸场/重拍/排期作废损失多少」

第3步 对照证据（SD-M1/M3/M5）
  同一故事：通用 LLM + 人肉 vs 我们
  要拍出的数字：改稿轮次、人工对齐分钟、约束违规数、锁定冲突数
  过稿率只做统计上报，不做承诺
```

## 4. 综合判定与决策

### 4.1 判定表

| 维度 | 判定 | 理由摘要 |
|---|---|---|
| 市场存在 | **C 类存在 / B 类已死** | 过稿率 2–5%、599 元稿、43 万部供给；需求在转化率与风险，不在产量 |
| 框架材质 | **有真牌** | 连续性、约束、影响面、拍摄锁 |
| 当前占位 | **不利** | 生产叙事红海 + 买家选成订阅编剧 + 指标不对 |
| 不容拒绝 | **尚未；路径在 ③** | 锚定制作损失才成立；禁用过稿率承诺 |
| 是否继续投入 | **有条件 GO** | 只批准「换锚 + 换人验证 + 治理层纵切」；不批准按创作者写作工具加码 |

### 4.2 立刻要改的三处（不改代码，先改口径）

1. **北极星与对外叙事**：从「AI 写短剧剧本 / 接受分钟数」改为「**可拍分集交付与改稿治理**」；禁止任何过稿率承诺。
2. **SD-M0-01 样本构成**：必须含承制/主创，问题改成损失与转化，不是「会不会用 AI 写作」。
3. **首版卖法假设**：订阅（编剧）→ **项目制/额度制（承制、有正在改的戏）** 作对照假设一并访谈；不要提前锁定一种。

### 4.3 否决条件（触发则停）

- 承制/主创对「改稿影响 + 已拍锁定」均表示「不为此付钱，有微信就够」→ 框架无买方，**停产品扩面，内核另用**。
- 同题对照中，通用 LLM + 简单模板在改稿轮次与对齐时间上与我们持平 → **无差异化，停**。
- 只能靠「提高过稿率」卖，但又无法出示可复核数据 → **不得销售，停**。
