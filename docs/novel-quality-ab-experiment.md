# 小说质量对照实验（A / B / C）

日期：2026-09-11；状态：实验设计与历史结果归档参考。

> **现行生产默认（2026-09）**：`STABLE_EXECUTOR = director_script_scene`
> （四剧本选题 → 择优 → 分场演绎）。下文中「默认仍 director_v2 / script 仅灰度」
> 为实验当时表述，**不能用来认证当前默认链路**。历史 A/B/S 人工反馈只对应当时方案。

## 目的

证明或否证：导演整场结算链路是否在相近预算下带来更好的阅读效果。
精简与预算暂停已证明「更可控」；本实验只回答「是否更好看」。

## 冻结范围

本轮实验期间禁止：

- 新增角色编排、记忆层、重试次数或调度系统
- 静默替换生产默认 `director_v2@2`
- 用提高 `MAX_CALLS` 或换更贵模型作为「变好看」的手段

允许：

- 已落地的无进展止损与核验预留小补齐
- 离线对照脚本与盲评表
- 实验臂 C 仅作为脚本协议，不进入 `KNOWN_EXECUTORS`

## 三方案

| 方案 | 协议 | 目的 |
|---|---|---|
| A | 设定 + 章节目标 → 直接写作 → 一次事实核验 | 简单基线 |
| B | 场景规划 → SCENE 结算 → RENDER → WATCH → VALIDATE（离线镜像生产链） | 测量现有导演链收益 |
| C | 导演给出动机/冲突/边界 → 执笔完成场景 → 再提取事实并核验；通过后才进正式状态 | 验证「提前冻结事件」是否限制质量 |

C 的关键约束：新事实先是草稿；核验通过才写入正式世界状态。

实现位置：`core/src/regent/novel/experiments/quality_ab.py`（实验包，非生产执行器）。

## 样本

固定 3 个**网文金手指**题材（同一总预算、同一模型）：

1. `f1_appraisal` 鉴宝都市《真假一目》：真伪浮层金手指，当众打脸与暴露风险  
2. `f2_reborn` 重生逆袭《催债那天》：重生先知 + 改命校正代价  
3. `f3_awaken` 异能觉醒《血偿一刀》：受伤觉醒血债可视/索偿，反噬自身  

禁止平凡无外挂日常开局。产品目标是付费网文。

## 预算与停止条件

- 每片段硬顶：调用次数与金额在脚本中钉死（默认 calls≤24、cost 分另计）
- 任一样本触及预算、无进展止损或契约失败 → 记失败并停止该样本，不追加额度凑成功
- 整轮停止：3×3=9 份全部跑完，或累计费用达到实验上限
- **不得**用替换失败运行来凑足成功数

## 盲评（只评四项）

评分人看不到方案字母。每项 1–5：

1. 想不想继续读
2. 人物是否鲜明
3. 选择是否有可信代价
4. 文字是否有现场感

同时记录：完成率、调用数、费用、硬核验失败数、是否用过修订。

`key_map.json` 仅实验主持可见；评委只看 `blind/<blind_id>.txt` 与评分表。

## 判定

- 若 B 在相近预算下不能稳定优于 A（盲评总分与「想继续读」），则进一步收缩导演链，只保留场景设计与关键取舍。
- 若 C 优于 B，再考虑把「后置抽事实」升为对照臂实验，**未证明前不替换生产默认**。

## 运行

```text
# 干跑：只输出协议清单与空白评分表
python deploy/novel/quality_ab_harness.py --dry-run

# 假模型贯通 9 样本（不付费，验证协议与落盘）
python deploy/novel/quality_ab_harness.py --sim --out deploy/novel/artifacts/quality_ab/

# 本机实跑（需本地 REGENT_MODEL_*）
set NOVEL_QUALITY_AB_LIVE=1
python deploy/novel/quality_ab_harness.py --live --out deploy/novel/artifacts/quality_ab/

# 远端实跑（容器已有模型配置；不重启服务）
python deploy/novel/run_quality_ab_live_remote.py
python deploy/novel/run_quality_ab_live_remote.py --protocol A --fragment f1_watch
```

产物：`deploy/novel/artifacts/quality_ab_live/`（`results.json`、`key_map.json`、`blind/*.txt`、评分表）。

## 已完成的一轮远端实跑（2026-09-11）

模型：`deepseek-v4.1-flash-tx-260911`；9/9 跑完；失败样本保留。

| 方案 | 完成率(系统) | 均调用 | 均费用(minor) | 字数范围 |
|---|---|---|---|---|
| A | 3/3 | 2.0 | 3.7 | 999–1871 |
| B | 2/3 | 5.3 | 8.7 | 469–769（最短） |
| C | 3/3 | 5.0 | 9.7 | 904–1387 |

### 人工阅读结论（盲评）

**九份几乎都不可用**：偏提纲/速写，现场感与可读章节长度不够；B 尤其短。  
因此：**本轮不能证明任何方案「更好看」**；系统 `completed=True` 此前几乎只表示「流程跑完」，不能当质量过关。

方向判断：

1. 停止扩大导演架构；B 在费用与长度上都不占优。
2. 先抬写作地板：实验已加 `MIN_PROSE_CHARS=2500`，过短不得记完成。
3. 未达到可读地板前，不做 A/B/C 胜负晋级；下一轮若重跑，先只验证「能否写出够长且可盲评的正文」。

定位说明：实验 brief 写的是「完整场景片段」，**不是**「小说第一章开场」契约。模型常自拟冷开场或中段潜入戏，读者缺少前文锚点时会像半截章。若按「开头」标准审，三份都不合格——与本次人工结论一致。

下一步仍冻结导演扩容：先把实验契约改成「必须作为第一章开场独立成立」，并加最低可信约束（经济动机自洽、人物关系一句内可懂）；未过门前不比较 B/C。

### 对架构的含义（冻结）

1. 导演扩容继续冻结；B/C 本轮无需再比——连直接写作 A 都未达到网文开场吸引力。
2. 下一瓶颈不在调度，而在**开场钩子与类型预期**（网文首章要抓人，不是把事件写清楚即可）。
3. 若再做小实验，只动提示/题材钩子约束（首段冲突前置、代价可见、禁止温吞铺垫），不加角色层/记忆层/重试系统。未证明「想继续读」前，不把任何协议升为生产默认。

### 路线纠偏（重要）

连续多轮只死磕协议 A（一次性直接写作），是把实验目标拧歪了。

**即刻冻结：** 不再为「一次性出好结果」继续加提示/改字数门重跑 A。

### 协议 S：两剧本择优（2026-09-11 接线）

依据：[导演式小说框架研究报告](novel-director-framework-research.md) 阶段 2。

```text
编剧候选α → 编剧候选β → 导演择优+执导要求
→ 程序装配（仅选定稿）→ 整章执笔 → 核验 → 导演整章验收
```

- 实现：`quality_ab.py` 协议 `S`（`script_select_then_write`）
- **领域模型同源**：`domain/script_protocol.py`（实验 S 与生产对照臂 `director_script@1` 共用）
- 生产对照臂已进入 `KNOWN_EXECUTORS`，**默认仍不选**；需显式
  `NOVEL_EXECUTOR_CANARY=director_script`（默认比例 0）
- 弃选剧本进 `artifacts.rejected`，不得进入 `production_packet` / 正式事实
- 故障三分：`supply` / `pick` / `render`（见 `fault_taxonomy`）
- 差异化加深：`SCRIPT_DIVERSITY_CONTRACT`（行动路径与代价类型可区分，禁止同梗换皮）

```text
# 只跑新切片（假模型）
python deploy/novel/quality_ab_harness.py --sim --protocol S

# 对照：基线 A + 旧镜像 B + 新 S（仍不改生产）
python deploy/novel/quality_ab_harness.py --sim --protocol A --protocol B --protocol S
```

晋级条件仍是阅读意愿，不是系统 completed。未证明前不迁移生产、不删旧演绎分支。

### 人工七轮结论（金手指 A/B/S）

**明显好于前几轮**：有代入感，也有钩子；钩子深度不够，套路化明显、创新不足，但**已经够用**。

含义：

1. 网文定位 + 金手指开局是必要前提；平凡日常题材不适用本产品。  
2. 「讲清楚 / 有代入 / 有钩子」已被验证可达到可用门槛；下一刀若继续，应加深钩子与差异化，而不是再退回无外挂现实开局。  
3. 导演式「剧本择优」路线值得在此可用门槛上继续比，而不是再死磕一次性提示工程。
