## 0. 一句话

**Regent 永远边跑边干边想：大模型尽可能自己把意图拆清并给出可执行方案；拆不清时再请人在有限选项上辅助决断。不怕预算花掉，怕的是花了却学不会。**

---

## 1. 模糊意图怎么处理（已定）

| 情况 | 系统行为 | 人的角色 |
|---|---|---|
| 模型能拆解清楚，且能推演出可执行路径 | **给出模型方案**（假设、步骤、未知项、拟用路径），按人做事的步骤往下推进 | 可纠偏、可改约束；不是开工前必填问卷 |
| 模型无法推演清楚 | **逐步理清**：向用户提出少量可选方案 / 关键分叉，逐项确认 | **辅助决断**（选 A/B、否决假设），不是替模型写完整 PRD |

原则：

1. **以大模型自己理清为核心**，人是辅助决断，不是主访谈官。  
2. **不是 Goal 前外挂工作室**——澄清、方案、执行同属一条 Goal 生命，不另起一套产品。  
3. **不设「形成阶段退出条件」作为产品哲学**——不搞「澄清毕业才能干活」。该开跑就开跑；错了就报错、记经验、再争预算与资源、重开或续跑。  
4. 与 C1（快照启动 + 事后纠偏）兼容：启动可以早；「理不清」时插入选项确认，而不是假装已经清楚。

### 1.1 明确否定的问法

- ❌「澄清是外挂还是门闩式形成阶段？」——错误二分。  
- ❌「退出条件是 unknowns=0 / 清晰度分数？」——Regent 不靠毕业门槛活；靠报错 + 经验 + 重开。  
- ❌「人必须先把 Goal 谈精准再允许系统动手」——违反模型主理。

## 2. 做事方式：按人的步骤，一步步来（已定）

1. **任何能力不要求一次性到位**；按人做事的步骤拆开实现、爬通、跑顺。  
2. **默认禁止「聪明绕路」**：在人的步骤尚未爬通跑顺前，不允许为了速度发挥新捷径。  
3. **允许尝试新路径的前提**：已有证据表明绕过某步后，产出稳定性 **不低于** 已跑顺的人步路径（对照样本 / 门禁），再开实验轨。  
4. 这同样约束 Agent 内核：submit / verify / Preview / 证据环是人步；流式、自由 spawn、未证 cache 技巧等，不得以「像 CC」为由插队。

## 3. 预算与经验（已定）

| 可接受 | 不可接受 |
|---|---|
| 边跑边想，探索与返工消耗预算 | 消耗预算却**不落经验**、下次重复同一失败 |
| 报错、累计 failure_lessons、再申请预算/资源重开 | 静默重试同策略直到耗尽，无结构化教训 |
| 缓存命中差 → 被观测到 → **学会**改布局/断点/清单 | 缓存命中差 → 只报警或只写进 ledger → **学不会优化** |

**真正的问题定义（示例）**：不是「曾浪费过 token」，而是「明明 cache 命中很差，系统却学不会优化」——观测而无闭环吸收 = 缺陷。

现网已有钩子（未宣称完成闭环）：`failure_lessons` 注入 acceptance、progressive-snapshot、`goal_clarity_state`、ledger `cached_tokens`。方向要求把这些从「偶尔写入」升级为 **可吸收的经验回路**（下一切片议题，非本文实现）。

## 4. 对人 / 对模型的分工（已定）

```text
模糊意图
   │
   ├─ 模型可推演 ──► 提出方案（步骤·假设·未知）──► 按人步执行
   │                      │
   │                      └─ 用户可随时纠偏（辅助）
   │
   └─ 模型推演不清 ──► 给出有限选项 ──► 用户决断分叉 ──► 继续推演/执行
                              │
                              └─ 仍不清则继续问关键分叉（少而硬），不倾倒问卷
```

人介入优先用于：**分叉决断、硬约束、权限/外部效应**；不用于替模型完成本可自洽的拆解。

## 6. 实现纪律（切片原则，非一次做完）

按人步顺序推进（示例序，可调但不可跳步装完成）：

1. **方案可见**：模型拆解结果以结构化方案/选项呈现给用户（非仅后台 metadata）。  
2. **推演不清门**：检测「无法自洽」→ 触发有限选项确认（人辅助决断）。  
3. **错误即经验**：失败路径稳定写入可复用 lessons，并在下一次争取预算/重开时强制注入。  
4. **学习闭环样例**：以 cache 命中为第一示范——差命中必须能驱动可观测的优化动作或明确实验结论，而非只探针报警。  
5. 以上每步爬通后，才允许讨论捷径/绕路实验。
