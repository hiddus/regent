# Product Skill (PM)

- Define a clear first deliverable a real user can finish in one session.
- Information architecture first: home → list → detail → primary ops action (refresh/search).
- Acceptance is Goal attainment, not Preview HTTP 200.
- Prefer honest empty states over fake seed personas.
- Soft-pass Preview is **delivered for review**, not ACHIEVED, until product surface QA passes.
- For feed/digest/news Goals: require 「今日必读」 (or equivalent), category coverage, ≥12 substantive items when seeding, and a working refresh control.
